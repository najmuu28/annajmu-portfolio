# Reizha Natsumi — Portfolio Website

Website portfolio bergaya editorial hitam-ungu, terinspirasi dari gambar referensi.

## Isi folder
- `index.html` — struktur dan semua teks/konten website.
- `style.css` — warna, typography, layout, animasi visual, dan responsive design.
- `script.js` — menu navigasi mobile dan tahun footer.

## Cara menjalankan
1. Ekstrak folder jika menggunakan ZIP.
2. Buka folder di VS Code.
3. Klik kanan `index.html` lalu pilih **Open with Live Server** (jika ekstensi Live Server terpasang), atau buka `index.html` langsung di browser.

## Cara mengedit
- **Nama, deskripsi, email, link sosial, judul project, dan skill:** edit di `index.html`.
- **Warna utama:** edit variabel di bagian `:root` pada `style.css`.
  - `--bg`: warna latar.
  - `--purple`: ungu utama.
  - `--purple-bright`: ungu terang.
  - `--text`: warna teks.
- **Interaksi menu mobile:** edit di `script.js`.

## Sebelum dipublikasikan
1. Ganti `hello@example.com` dengan email milikmu.
2. Ganti link Instagram, Behance, dan GitHub dengan akunmu.
3. Ganti nama/teks bila ingin memakai nama profesional yang berbeda.
4. Ganti empat kartu project contoh dengan karya asli. Kartu saat ini dibuat sebagai visual placeholder menggunakan CSS, jadi tidak memerlukan file gambar tambahan.

Font menggunakan Google Fonts; jika internet tidak tersedia, website tetap berjalan dengan font cadangan.
